NMRSIMPY · v0.1.0

nmrsimpy：Python 里的脉冲程序仿真

读取 Bruker 脉冲程序（.pp）和自旋体系（.ham），演化密度矩阵并合成 FID，无需打开 TopSpin。多数实验族的 FID 与 NMRSIM 输出的余弦相似度不低于 0.99。

  • 直接运行真实 .pp 文件：语料库 808 个文件中 761 个可解析
  • 密度矩阵仿真，覆盖脉冲、延时、J 耦合、频偏与强耦合项（最多 11 个自旋）
  • 支持成形脉冲、梯度（echo/antiecho）、去耦与 T1/T2 弛豫
  • 1D、2D（QF、echo-antiecho、TPPI）与 N 维执行器
  • 编译期错误检查，与 NMRSIM 内核的报错信息对齐
  • 依赖精简：numpy 与 bruker-lark，Python 3.10+

已知限制：不支持超过 11 个自旋，不支持 CW 与 chirp 脉冲，脉冲期间的弛豫未建模。

# run one dataset
$ nmrsimpy run exp41/

# 2D run, save FID and plot the spectrum
$ nmrsimpy run exp57/ --td1 256 \
    -o s.npz --plot spec.png

# custom pulse program + spin system
$ nmrsimpy run sim.cfg \
    --pp my.pp --ham ethanol.ham

# batch over many datasets
$ nmrsimpy batch /path/to/datasets \
    --out-dir results/ --limit 50

GRAPHPULSE · v0.1.0

GraphPulse：看得见的脉冲程序

把 Bruker .pp 文件渲染成 TopSpin 风格的泳道时序图，并与源码保持同步。可在浏览器里查看、编辑与导出。

  • 泳道视图：f1、f2、grad、delay、acq、meta，对齐的脉冲同时显示
  • 双向联动：点击事件高亮源码行，点击源码行高亮事件
  • CodeMirror 在线编辑，修改后实时重新解析，无需刷新页面
  • 可选 AI 灰字补全：配置兼容 OpenAI 的上游后按 Tab 采纳
  • 仿真工作区（开发模式）：SLEEPY、Prodopy，以及 Spinach 与 TopSpin 并排对比
  • 中英双语界面与明暗主题；示例库含 26 个脉冲程序

BRUKER PULSE PROGRAM · v3.0.0

Bruker PP：.pp 文件的 IDE 级体验

在 VSCode 中获得完整的 Bruker 脉冲程序开发支持：TextMate 语法高亮、LSP 智能补全、Lark 解析器校验、AST 查看与 30+ 代码片段。

  • 语法高亮：基于完整 EBNF 语法，覆盖脉冲、延时、相位、梯度、去耦等全部元素
  • LSP 智能：悬停文档、自动补全、跳转定义、查找引用、重命名与语义高亮
  • 实时验证：Lark Earley 解析器逐字符校验，错误精确到行列，中文提示
  • AST 查看：一键将脉冲程序解析为抽象语法树，格式化 JSON 输出
  • 30+ 代码片段：calc、ph、pg、go、mc、lo、gron/groff 等常用模式一键插入
  • 自动补全：p0-p63、d0-d63、ph0-ph31、通道修饰符与用户自定义符号
